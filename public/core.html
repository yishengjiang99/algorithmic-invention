Core

A band-limited wavetable written in C. The C is in this file’s source. On Start, wabt is fetched from jsDelivr and assembles it to WASM on the audio thread.

Band-limited oscillator

Mipmapped saw / square in an AudioWorklet. C is compiled in-page via wabt (jsDelivr). 5 ms gain ramp, 8 ms pitch ramp.

Voices

Extra voices detune around the root. Gain is equal-power scaled.

JS DSP versus WASM DSP

Same oscillator loop, two languages. Hypothesis: WASM pulls ahead as voice count rises, but JS stays competitive at one voice because of the boundary call.

Real-time memory discipline

WASM memory is linked initial = max = 1 page (64 KiB). Growth is impossible. process() constructs no arrays. A 32-voice run should report zero NaN/Inf and zero deadline overruns.

Timing model

The audio thread wakes once per 128-frame quantum (~2.9 ms at 44.1 kHz). That interval is the deadline. View-source this page for the C. wabt@1.0.36 is the over-the-air assembler; render(n) is the only JS↔WASM call per quantum.
